#define
RADAR_FIXED_BYTES_MAX

Encoded bytes an update may spend on everything that is not the contact list. Anything that never changes belongs in ui_static_data(), which is sent once, rather than in here, which is sent forever.

#define
RADAR_PUSH_BYTES_MAX

Encoded bytes a single push is allowed to reach, at any contact count.

One batch of contacts plus the fixed keys. url_encode() turns every quote, colon and comma into three bytes, so on a ten field entry the JSON punctuation costs more than the values do, which is why a contact runs to a few hundred bytes and this budget looks generous for fifteen of them.
