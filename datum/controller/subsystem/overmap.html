proc
log_overmap_footprint
()

Account for what the grid cost in Z levels.

Which ruins get seeded is a weighted draw, so two rounds on the same map can differ by several full levels of turfs, and BYOND does not hand a Z back once it has been taken. That variance is invisible from the outside until a heavy map runs out of memory partway through a round, so the draw is worth writing down next to the size it cost - the template ids included, since the interesting question after a failure is usually which ruins came up.
