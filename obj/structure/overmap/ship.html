/tg/ Station 13 - Modules - Types — Var Details - Proc Details

ship
/obj/structure/overmap/ship

Anything on the overmap that's capable of self-propelled motion.

Vars

available_thrustFull-output thrust currently available for the assisted envelope/braking. Unlike est_thrust, this is independent of commanded throttle and spool.
control_flagsShip control flags (SHIP_CONTROL_CONSOLE, SHIP_CONTROL_DIRECT).
desired_angleDesired heading angle in degrees (0=east, 90=north, math convention).
desired_throttleDesired throttle 0..1 (fraction of max_speed).
has_headingWhether a heading has been set (FALSE = drifting/stopped).
max_speedCurrent flight-assisted speed envelope in tiles/second. Refreshed from available full-output thrust and ship mass.
station_keepingStation-keeping mode active.

Procs

all_stopAll-stop: zero throttle, clear heading, and begin braking. Braking rate is proportional to thrust/mass — light ships with good engines stop fast, heavy ships take longer.
apply_brakingApply braking deceleration toward zero velocity. Called each physics_tick when has_heading is FALSE and ship is not yet still. Uses the same full-output authority that defines the assisted speed envelope, guaranteeing a stop within OVERMAP_ASSIST_BRAKING_DISTANCE while available.
apply_station_keepingStation-keeping logic, invoked from ship's physics_tick when station_keeping is TRUE. Modifies vel_x/vel_y directly to converge on orbital velocity.
burn_directionApply thrust in a given 8-direction. Converts direction to angle, sets desired heading and throttle. Used by legacy console directional buttons and relaymove from pilot link.
can_full_stopHelm full-stop command. Meaningful velocity still brakes physically, while drift at or below one percent of the current envelope settles immediately.
dir_to_physics_angleConvert a BYOND 8-dir to physics angle in degrees (math convention: 0=east, 90=north).
get_available_accelerationAcceleration available at full output in tiles/s².
get_available_thrustFull-output thrust presently available for the flight envelope and braking. Simulated ships override this with an engine/power/ISP-aware sum.
get_effective_massEffective mass for accel/brake. Simulated ships use turf-count mass.
get_effective_thrustLive thrust for velocity convergence. Simulated ships use burn est_thrust while thrusting; otherwise rated thrust remains the legacy fallback. Braking and the assisted envelope use get_available_thrust() instead.
get_headingHeading bitfield from current velocity components (for icon direction).
get_heading_degreesHeading in degrees (0-359, 0=north clockwise) from velocity vector.
get_speedCurrent speed magnitude in tiles/second.
has_gravity_influenceWhether any gravity well is currently influencing this ship.
is_stillWhether the ship is effectively stationary.
on_axis_blockedHandle blocked movement by zeroing velocity on the blocked axis.
physics_tickPhysics integration. Applies thrust toward desired velocity, integrates position. Called by SSfastprocess via process() each tick.
refresh_flight_envelopeRefresh the assisted target-speed envelope from stopping distance.
set_desiredSet the desired heading and throttle. Called from helm UI act("set_desired"). angle is in degrees (math convention: 0=east, 90=north).
