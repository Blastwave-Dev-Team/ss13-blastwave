/tg/ Station 13 - Modules - Types — Var Details

level
/obj/structure/overmap/level

Z-level linked overmap objects. Stations and mining sites are level objects; ships dock at them via SSshuttle. The base type carries the shared linkage machinery so M2's concrete subtypes (main, mining/lavaland, mining/ice) can stay declarative.

Vars

custom_dockingIf the shuttle nav console can change the docking location.
installation_stealthWhen TRUE, visibility to other ships is filtered via SSovermap.can_view_installation(). Only main + des_two use this.
linked_levelsZ-values this overmap tile maps to. Multi-Z mining maps populate this with all ZTRAIT_MINING levels so a single icon represents the entire body (Snowglobe, Icebox, etc).
