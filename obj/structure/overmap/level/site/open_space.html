Destroy

Hand the content Z back on a timer rather than with INVOKE_ASYNC.

INVOKE_ASYNC is spawn(), and a spawn inherits the enclosing proc's src. The recycle walks every turf on the Z, so spawning it from here would keep this object referenced for the whole sweep - long past the point the collector gives up and hard deletes us. The reference lives in an execution context rather than a variable, so ref tracking cannot see it either. A timer hands the work to SStimer, which only needs the Z number.
