/tg/ Station 13 - Modules - Types — Var Details - Proc Details

celestial
/obj/structure/overmap/celestial

Base celestial body type. Has mass, sphere of influence, and optional Kepler orbital parameters.

Vars

eccentricityEccentricity: 0 = circle, 0..1 = ellipse.
gravity_massGravitational mass. Determines pull strength on ships within SOI.
orbital_parentWeakref to the body this celestial orbits (null = fixed position).
orbital_periodOrbital period in seconds for one full revolution.
phase_offsetStarting phase angle in degrees.
pxCached: absolute pixel X of this body (for gravity calcs).
pyCached: absolute pixel Y of this body (for gravity calcs).
semi_major_axisSemi-major axis in pixels (orbital radius for circular orbits).
soi_sqCached SOI^2 to avoid sqrt in distance checks.
sphere_of_influenceSphere of influence in pixels. Beyond this distance, gravity is ignored.

Procs

escape_velocityCompute escape velocity at a given distance from this body.
orbital_velocityCompute required circular orbital velocity at a given distance.
set_orbital_parentAssign an orbital parent and register for per-body orbit ticks.
update_orbitUpdate position from Kepler orbital parameters. Ticked by SSfastprocess via process() when orbital_parent is set. Fixed bodies skip processing.
update_orbit_registrationStart or stop SSfastprocess ticks for Kepler orbit integration.
update_pixel_posSync cached pixel position from tile + fractional offset.
