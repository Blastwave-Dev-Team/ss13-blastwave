overmap_landing_zone
/obj/effect/landmark/overmap_landing_zone

Landing-zone claim held while a shipyard build is active.

Vars

dock_affiliationOvermap affiliation allowed to land here (OVERMAP_AFFILIATION_*). Null/empty = open to any affiliation (seeded/mapped zones default open).
exit_directionCardinal direction a docked shuttle must have a clear launch path toward. Read by the bay-exit check at undock time. NONE means "no designated exit" (bay-exit falls back to checking all four faces).
zone_heightHeight of the landing region in tiles (Y axis).
zone_nameDisplay name shown in the nav console jump menu.
zone_widthWidth of the landing region in tiles (X axis).

Procs

can_fit_shuttleReturns TRUE if a shuttle with the given width/height can fit within this zone in at least one rotation (0 or 90 degrees).
contains_bboxReturns TRUE if the given bounding box (x1,y1 to x2,y2) is entirely within this zone.
contains_turfReturns TRUE if the given turf lies within this zone's bounds.
get_center_turfReturns the center turf of this zone for camera eye placement.
get_occupantReturns the first mobile shuttle whose footprint overlaps this zone's bbox on the zone's Z, or null if the zone is clear. ignore_port is skipped so a navigating shuttle does not count itself as an occupant.
