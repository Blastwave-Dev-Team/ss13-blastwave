Vars

active_zoneThe landmark we manage while the linked corners form a valid zone.

cornersWeakrefs to the linked /obj/machinery/landing_corner beacons (max 4).
dock_affiliationOvermap affiliation stamped onto the managed landmark (OVERMAP_AFFILIATION_*). Null = open docking (any affiliation).
exit_directionCardinal launch/exit direction pushed onto the managed landmark. The bay-exit check validates the shuttle's clearance toward this edge at undock time.
invalid_reasonReason the zone is not currently valid, for the UI/examine. Null when valid.
oversizedTRUE when the last computed rectangle exceeded the size cap.
zone_labelPlayer-facing name pushed onto the managed landmark.
zone_width_cacheLast computed zone dimensions, cached for the UI/examine.
