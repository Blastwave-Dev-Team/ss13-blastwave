bus
/obj/machinery/overmap_radar/bus

Junctions for the radar chain, split by which side of the processor they sit on.

One bus doing both jobs is what made the topology cyclic: it fed the processor and the processor fed it back. Two roles at fixed stages means the packet can only ever move forward, so the array an operator builds is a pipeline no matter how they wire it.
