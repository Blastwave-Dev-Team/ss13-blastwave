/tg/ Station 13 - Modules - Types — Var Details - Proc Details

main
/obj/machinery/unstable_field_generator/main

The interactable core.

Map this on the bottom-middle tile of the intended 3x3 footprint, same as the real gravity generator. Starts running, holds the global unstable bluespace field, and only lets go once every required keycard has been swiped and someone pulls the breaker.

Vars

blast_door_idsBlast doors interlocked with the field. Mapper-set; each entry matches the id on the doors themselves.
breakerWhether the breaker is engaged. Goes false when someone with all the keys pulls it.
breaker_spentSet once the field has collapsed. The breaker is a one-way trip: the authorizations that freed it are spent, and the whole point of the set piece is that shutting it down sticks.
center_partThe middle piece, which carries the animated core overlay.
charge_count0 to 100. Ramps toward whichever end the breaker points at, and flips on when it gets there.
charge_rateCharge percent gained per process tick while climbing. Refilling a capacitor bank is the slow direction, so a change of heart before the field drops costs real time.
charging_stateFIELD_POWER_IDLE, FIELD_POWER_UP or FIELD_POWER_DOWN.
current_overlayWhich core overlay is currently applied.
discharge_rateCharge percent shed per process tick while collapsing. SSmachines ticks every 2 seconds, so 15 empties a full bank in about fifteen: fast enough to read as an event, slow enough that there is still time to be somewhere else when it lets go.
field_colorTint applied to the whole housing so it reads as "not the gravity generator you know".
generator_partsThe eight surrounding housing pieces.
onWhether we are currently holding the global field up.
required_puzzle_idspuzzle_id values that must all be slotted before the breaker will move. Mappers set this.
slotted_cardsKeycards physically sitting in the reader, oldest first. These are the authorisation: pulling one back out re-locks its slot, so the state lives on the cards the machine is actually holding rather than in a parallel list that could drift out of step with them.

Procs

ExitedKeeps the slot list honest if a card leaves by any route other than eject_card() — admin yanking, the machine being taken apart, or anything else that empties our contents.
accepted_puzzle_idspuzzle_ids of every card currently in the reader.
announce_collapseLets everyone who has been suffering through the field know that it just dropped.
eject_cardPops the most recently slotted card back into the user's hands, re-locking its slot.
interactEmpty hand takes a card back out. The breaker is deliberately not on this input: throwing it is irreversible, and the click that fills the last slot must not also be the one that fires it.
missing_puzzle_idsWhich required puzzle_ids have no card in their slot yet.
pull_breakerThrows the breaker, if every slot is filled and it has not already been spent.
set_powerPoints the ramp at whichever end the breaker calls for.
setup_partsBuilds the eight surrounding housing pieces, 3x3 block anchored on our tile as the bottom middle.
update_core_overlayMirrors the gravity generator's charge animation so the machine reads as the same hardware.
