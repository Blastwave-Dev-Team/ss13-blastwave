Title: Mapping

MODULE ID: MAPPING

Description:

For adding new assets to be utilised by mappers and admins in-game. This is for entirely new assets. Got a new Halloween-themed turf for an event map? Goes here. If you want to overwrite TG assets, place that in the AESTHETICS module.
