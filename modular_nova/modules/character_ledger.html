Character Ledger

Module ID: CHARACTER_LEDGER

Description

Persistent per-character Nanotrasen credit ledger, plus an ATM that moves credits between that ledger and the round ID account. Identity is an immutable character_uuid on character prefs, copied onto the mind at spawn. Ledger rows are INSERT-only. ATM deposits need no PIN; withdrawals require the character PIN each click.
